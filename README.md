### 第二步：登录自己的 ChatGPT 账号

WildAI 的流程不是给你一个共享账号，而是尝试把订阅开通到你自己的 ChatGPT 账号。

按照官方教程，需要先在同一浏览器里登录 ChatGPT，然后回到订阅页面继续操作。页面会提示你打开 ChatGPT 的会话信息页面，复制一段 JSON 内容，再粘贴回 WildAI。

这段 JSON 不是普通的邮箱地址。它属于账号登录会话相关的订阅凭证，虽然平台教程称其用于本次开通，但仍然应该按高敏感信息处理。

提交前至少确认三件事：

1. 当前浏览器登录的是你准备开通 Plus 的账号；
2. 页面识别出的邮箱地址正确；
3. 没有把这段内容发送给个人客服、群聊或其他第三方。

如果打开会话页面后显示空白或 `{}`，通常说明当前浏览器没有正确登录 ChatGPT，或者登录状态没有被识别。此时不要把空白内容反复提交，先回到 ChatGPT 页面确认账号状态。

WildAI 页面会显示识别到的 ChatGPT 邮箱。官方教程特别提醒，开通错误账号后通常不能简单转移订阅，因此付款前必须核对清楚。

## 提交账号凭证时要注意什么？

这是使用第三方订阅服务时最需要认真看的一部分。

WildAI 的 ChatGPT 教程要求用户从已登录的 ChatGPT 浏览器中复制一段 JSON，并提交到订阅流程。官方页面同时提醒，这类凭证应当保密，不要发给其他人。

- 凭证只用于开通，还是也用于后续续费；
- 凭证会保存多久；
- 是否可以申请删除；
- 失败、退款或账号异常时由谁负责处理。

尤其不要把 ChatGPT 密码、邮箱密码、短信验证码或银行卡完整信息发送给个人客服。正常的订单流程应当尽量在平台页面完成，而不是通过私人聊天工具操作。

开通后，可以进入 ChatGPT 账号设置，确认 Plus 状态、订阅到期时间和活跃会话。如果发现异常登录、账号设置被修改或会话状态异常，应及时退出其他设备并修改密码。

付款失败不一定代表账号有问题，也可能是商品库存、支付渠道、会话凭证或风控验证失败。

在 WildAI 的订单页面查看订单是：

- 待支付；
- 处理中；
- 已完成；
- 已失败；

- 优惠是否只适用于首次购买；

### 最后联系平台客服

联系时准备订单号、付款时间、支付状态和页面截图。不要直接发送完整账号凭证，除非平台在正式订单流程中明确要求，并且你已经确认客服入口属于官方平台。
